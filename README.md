# Rodeo Stampede Games site

Static responsive website for `rodeo-stampede.com`.

- `index.html` is the turquoise game-mosaic homepage.
- `games/rodeo-stampede/` is the featured game page, with the iframe URL supplied by the site owner.
- 50 related game pages use the supplied CSV iframe links and matching local artwork.
- Each game page includes a guide of about 600 words and recommendations.
- `sitemap.xml`, `robots.txt`, and the requested `ads.txt` are included.
- The Google AdSense loader and account meta tag are included in the homepage and all game pages.

Deploy the contents of this folder at the web root for `rodeo-stampede.com`.
